# Piensa o Te Piensan (título provisorio)

Libro corto (ebook, ~40.000 palabras) sobre pensamiento crítico, para publicar en Amazon KDP y MercadoLibre, con traducción posterior a otros idiomas.

Ver `ESTRUCTURA.md` para el índice completo y el criterio editorial
(controversias documentadas con ambas fuentes, sin afirmar como hecho lo que sigue en disputa, y sin tratar el consenso institucional como veredicto por defecto).

Ver `NOTAS-REVISION.md` para el criterio de la revisión de evidencia (rama `revision-evidencia`).
